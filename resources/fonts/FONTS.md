# Fonts

Self-hosted latin-subset woff2 files, bundled by Vite from this directory
(referenced by relative `url()` in `resources/css/app.css`).

- Inter 400 / 600 / 800 — body and display grotesque.
- DotGothic16 400 — dot-matrix display face, hero numerals only.

Both faces via Fontsource, under the SIL Open Font License 1.1.
